The big idea

One kernel.
Two superpowers.

A Mercer kernel acts like a dot product in a transformed feature space. A Gaussian process uses a valid kernel as a covariance function: a rule for how outputs vary together. Same mathematical object, two useful viewpoints. Start with nearby points. Finish with a distribution over entire curves.

What makes a kernel valid? And what does Mercer’s theorem add?

A valid real covariance kernel is symmetric: k(x,z) = k(z,x). For any finite set of inputs, the matrix K with Kᵢⱼ = k(xᵢ,xⱼ) must be positive semidefinite: aᵀKa ≥ 0 for every vector a. Symmetry alone is not enough. Positive semidefinite does not mean every matrix entry is positive; valid kernels can have negative values.

Under the usual continuity and compact-domain assumptions, Mercer’s theorem expands a kernel into eigenfunctions with nonnegative eigenvalues: k(x,z) = Σ λⱼ ψⱼ(x) ψⱼ(z). The features are √λⱼ ψⱼ(x). More generally, positive semidefinite kernels admit a feature-space inner-product representation. “Mercer kernel” is often used informally for such valid kernels.

How the prediction is calculated

We use a zero-mean GP prior and observations y = f(x) + Gaussian noise. Let C = K(X,X) + σₙ²I.

mean = K(*,X) C⁻¹y
covariance = K(*,*) − K(*,X) C⁻¹K(X,*)

The implementation solves these systems with Cholesky factorization, with tiny diagonal jitter for stability. Curves are joint Gaussian draws over a finite grid, connected for display.

What is actually “Gaussian”?

Pick any finite list of inputs. Their function values have a joint multivariate Gaussian distribution. A GP specifies compatible distributions like this for every finite list. The individual curves do not need to look like bell curves, and the kernel does not need to be Gaussian.

Read the band correctly.

The band is mean ± 1.96 standard deviations for the underlying function at each location, conditional on the chosen kernel and settings. It is not a 95% guarantee that an entire curve stays inside. Future noisy observations have extra variance σₙ². Confidence is only as good as the model assumptions.

With a fixed kernel and noise level, posterior uncertainty depends on where you observe, not the observed y-values. A large residual does not automatically widen the band. Hyperparameter learning can change that; this lab keeps the settings under your control.
